# Personal Developer Portfolio

A responsive personal portfolio landing page built with **HTML, CSS and vanilla JavaScript**.

## Features
- Responsive desktop, tablet and mobile layouts
- Mobile navigation menu
- About, skills, projects and contact sections
- Social links and email contact links
- CSS-built developer/code editor illustration
- Subtle animations and hover interactions
- Semantic HTML and reduced-motion support

## Run locally
1. Download and extract the project.
2. Open the `personal-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.

No build tools or installation are required.

## Personalize before publishing
Open `index.html` and replace:
- `your.email@example.com` with your real email address.
- `https://github.com/` with your GitHub profile URL.
- `https://www.linkedin.com/` with your LinkedIn profile URL.
- The sample project descriptions with your actual project repository/demo links.
- Update your education details or skills if they change.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `personal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.
